# 8899 工程参数层

8899 由两层组成：

- 稳定内核：相机、识别、RGB-D、IK、吸盘、复位和抓取 Skill；
- 工程参数层：任务高度、接近距离、试抬距离和具名 Pose。

日常现场调整只编辑工程参数层，不再修改主配置或重启服务。网页保存后，
下一次抓取立即读取新参数。数据原子写入：

`runtime/operator_parameters.json`

## 参数

- Task1：1/2/3 层接触法兰 Z、接近距离、试抬距离、运输 Z；
- Task2：单层盒接触法兰 Z、接近距离、试抬距离、运输 Z；
- Task3：扁盒接触法兰 Z、接近距离、试抬距离、运输 Z。

所有网页数值使用毫米，文件和 API 使用米。

## 具名 Pose

网页“读取当前 Pose”只连接机械臂反馈端点，读取位置、四元数和六个关节角，
不会切换模式或下发运动。“保存为具名 Pose”会再读取一次当前反馈并写入同一个
参数文件。建议名称：

- `home`
- `safe_transport`
- `pre_pick_carton`
- `pre_pick_blister`
- `pre_insert`

如果遥操正在运行，Pose 读取会拒绝，避免两个客户端同时占用机械臂。

当前版本只负责记录和显示具名 Pose；将 Pose 接入固定轨迹时，应由对应 Skill
显式引用名称，不允许网页直接回放任意 Pose。
