# 技能契约

上层工作流只依赖统一的：

```python
SkillResult execute(SkillRequest request)
```

真实硬件、ACT服务和dry-run模拟器都必须实现同一接口。每个技能返回：

- `ok`：是否达到技能出口条件；
- `retryable`：是否允许当前技能重试；
- `evidence`：真空、图像、夹爪开度、目标位姿等验收证据；
- `error`：失败原因。

## 操作技能

| 技能 | 入口 | 成功出口 | 首版路线 |
|---|---|---|---|
| `pick_carton(mode)` | 左臂在取料准备位，目标已定位 | 药盒被左吸盘持有并到达携带位 | 确定性 |
| `place_carton(slot_id, orientation)` | 持有成品药盒，大箱和槽位已定位 | 药盒释放且槽位占用正确 | 确定性 |
| `stabilize_carton()` | 中间药盒已定位 | 右夹爪稳定盒体且盒口无遮挡 | 确定性 |
| `pick_item(type, stage)` | 左吸盘空闲，目标药板/说明书已选中 | 单件物料被吸住并到达携带位 | 规则优先，ACT候选 |
| `insert_item(type, stage)` | 左吸盘持物，右夹爪固定药盒，位于统一预插位 | 物料完全进入并释放 | ACT候选 |
| `erect_carton()` | 左吸盘持有扁平盒坯 | 盒体成为稳定矩形截面 | 固定优先 |
| `close_carton(mode)` | 盒口和盖舌可见，盒体被稳定 | 小舌在内、主舌入槽、盖面齐平 | 混合 |

## 公共技能

| 技能 | 说明 |
|---|---|
| `safe_move(target)` | 回零、观察位、携带位、预插位和工位切换 |
| `verify(target)` | 只读验收，不得产生机械臂运动 |
| `safe_stop(reason)` | 立即禁止新运动并执行既定安全停机 |

## ACT边界

模型不负责：

- 三次计数；
- 工位切换；
- 长距离自由空间运动；
- 真空开关时序；
- 成功验收；
- 无限重试。

模型只处理短时、接触不确定的局部动作：

- `pick_item` 的最后接近与揭取；
- `insert_item` 的盒口对准与插入；
- `close_carton` 中的主插舌对准与插入。
